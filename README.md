# ruck — reader reports

ruck is a small rugby newspaper whose every story is written from a rating model's numbers:
[ruck.pages.dev](https://ruck.pages.dev).

This repository is where readers tell us when something is wrong or worth writing about. The
site's code is not here.

**Open an issue** to:

- **report a wrong score, date or venue**: name the match, and link to where you saw the right
  result;
- **report a wrong name**: a club, a player or a competition spelled or matched wrongly;
- **suggest a story**: a question about a team, a season or the game that the numbers could answer.

You need a GitHub account to open an issue.

[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/): reuse them freely, crediting ruck.
